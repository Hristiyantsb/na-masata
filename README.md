# На маса

Българско приложение за седмично меню, покупки и хранителен дневник. Версия 0.9.0 работи локално на устройството, без регистрация, абонамент и активна Cloudflare връзка.

**Приложение:** https://hristiyantsb.github.io/na-masata/

## Стартиране

```sh
npm ci
npm run build:offline
npm test
npm run check
npm run dev
```

Node.js 22.13+. Отвори http://127.0.0.1:4173. GitHub Pages публикува `main:/docs`; няма framework build. След всяка промяна в docs изпълни build:offline и включи docs/sw.js в commit.

## Готови локални функции

- Кратка настройка в 5 въпроса: магазини, насоченост и режим, уреди и време, какво не ядеш, калории на порция с хора, дни и бюджет. След тях преглед на подходящите рецепти. Започнатата настройка се възстановява на същия браузър.
- 23 рецепти, строг подбор според ограниченията, седмично меню, смяна, местене, повторение, заключване и връщане.
- Преизчисляване на порции, любими, бележки и запазени отметки по стъпките за готвене.
- Общ списък за покупки, наличности, допълнителни продукти, размер на опаковка и редактируеми примерни цени.
- Дневник с калории и макроси, лична цел, последни и запазени храни, копиране между дни, седмичен обзор, CSV и JSON импорт.
- Локален баркод декодер чрез камера, снимка или ръчен код. Познатите продукти се намират в личните записи; за новите се въвеждат стойности от етикета. Не е необходим продуктов сървър.
- Резервно копие, валидирано възстановяване, изтриване и съвместимост със старите данни.
- PWA с На маса wordmark, favicon, икони за телефон и офлайн пакет след първото успешно онлайн зареждане.

## Данни и ограничения

Данните са в браузъра на конкретното устройство. Използвай Настройки → резервно копие преди изчистване на браузъра или преместване. Отметките за готвене и недовършеният onboarding са помощни локални данни и не влизат в основния backup. Няма активни плащания, вход или синхронизация. Цените са примерни; хранителните стойности са приблизителни. Проверявай етикетите за алергени. Камерата изисква разрешение и HTTPS (или localhost).

## Бъдещ каталог и сървър

`server/` съдържа подготвен, но **неактивиран** Workers/D1 код. Не изпълнявай deployment или remote migrations без отделно възлагане. `docs/src/config.js` остава `mode: 'local'`, `apiBase: ''`. Запазеният legacy Supabase/Stripe код не се използва в тази версия.

За бъдещ импорт от книги: подготви проверен JSON със servings: 2, source и recipes. `node scripts/import-recipes.mjs input.json output.sql` валидира рецептите и генерира SQL локално; не го изпраща към D1. Използват се само познати продуктови идентификатори, за да не се загубят хранителните стойности и алергените. Импортът на PDF/книги не е автоматично извличане или публикуване.

## Дизайн и проверки

Идентичност На маса: дървена маса с очи като маскот, wordmark в Lora 700, PT Sans за интерфейса, forest green акцент върху топли неутрални повърхности. Ястията се рисуват като чинии в цветовете на собствените им съставки. Снимката в настройката е генерирана илюстрация, не точна снимка на рецепта. Референциите на конкурента не са включени в приложението. Лицензите на шрифтовете са в assets/fonts.

95 автоматизирани теста покриват домейн логиката, контролерите, безопасния markup, PWA, импортите и подготвения backend. Ръчно проверени desktop onboarding и мобилен поток до готово меню и отметка за готвене в Chromium. Реални iPhone/Android инсталации и камера не са проверени на физически устройства.
