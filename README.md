# На маса

Българско приложение за седмично меню, покупки и хранителен дневник. Версия 1.0.0 работи локално на устройството, без регистрация, абонамент и активна Cloudflare връзка.

**Приложение:** https://hristiyantsb.github.io/na-masata/

## Стартиране

```sh
npm ci
npm run build:offline
npm test
npm run check
npm run dev
```

Node.js 22.13+. Отвори http://127.0.0.1:4173. GitHub Pages публикува `main:/docs`; няма framework build. След всяка промяна в docs изпълни build:offline и включи docs/sw.js в commit.

## Какво прави

- **Онбординг с жива маса.** Шест кратки въпроса: магазини, как се храните, какво да е менюто, уреди и време, какво не слагаме на масата, за колко души. Векторната дървена маса играе всеки отговор: торби от веригите, чиния според режима, уредите, алергенът пада на пода, по чиния за всеки човек, капак над резултата. Жив брояч на подходящите рецепти; при нула масата заспива и предлага какво да промениш. Уважава „намалено движение“.
- **Меню за седмицата.** 118 рецепти, алгоритъм по режим, нужди, уреди, време, калории, магазини и бюджет; до три причини за всяко ястие. Сготвено, смени, премести, сготви двойно за утре, повтори, „Запази някои, смени останалите“, отмяна, заключване.
- **Рецепта и готвене.** Макроси на порция, порции +/−, цена на съставките, отметки по стъпките, бележки, любими; готвене стъпка по стъпка с таймер и екран, който не изгасва.
- **Покупки.** По магазин и щанд, цели опаковки, наличности вкъщи, лична цена и опаковка, допълнителни продукти, режим „Пазарувам“, копиране и изтегляне.
- **Рецепти.** Търсене, любими, „До 30 мин“ и кухни.
- **Дневник (Меню Плюс · демо), като MyFitnessPal.** Сканираш баркода и продуктът идва от Open Food Facts с марка, калории и макроси; търсиш в своите храни, основните продукти, рецептите и Open Food Facts; бързи калории; „Цел − Храна = Остават“; вода, тегло, копиране в дни, CSV и JSON. Към интернет излизат само цифрите на баркода или думите за търсене.
- **Още.** Напомняне в календара (.ics), резервно копие, възстановяване, изтриване, инсталиране, планове без плащане.
- Светъл и тъмен режим, телефон и компютър, PWA офлайн, автоматично обновяване.

## Данни и ограничения

Данните са в браузъра на конкретното устройство. Използвай „Още“ → резервно копие преди изчистване на браузъра или смяна на телефона. Няма активни плащания, вход или синхронизация. Цените са примерни; хранителните стойности са приблизителни. Проверявай етикетите за алергени. Камерата изисква разрешение и HTTPS (или localhost).

## Бъдещ каталог и сървър

`server/` съдържа подготвен, но **неактивиран** Workers/D1 код. Не изпълнявай deployment или remote migrations без отделно възлагане. `docs/src/config.js` остава `mode: 'local'`, `apiBase: ''`. Модулите за акаунт (`auth.js`, `api.js`, `diary-sync.js`) не са свързани с интерфейса.

За бъдещ импорт от книги: подготви проверен JSON със servings: 2, source и recipes. `node scripts/import-recipes.mjs input.json output.sql` валидира рецептите и генерира SQL локално; не го изпраща към D1.

## Дизайн и проверки

Идентичност На маса: логото и иконата на потребителя, маскотът като векторна маса (`docs/src/table.js`), бял фон, горско зелен акцент, системен шрифт. Един CSS файл (`docs/assets/styles.css`) и движенията на масата (`docs/assets/table.css`). Ястията се рисуват като чинии от съставките им; не са снимки.

117 автоматизирани теста покриват домейн логиката, алгоритъма, онбординга, изгледите, безопасния markup, PWA, импортите и подготвения backend. Два от тях зареждат истинския `app.js` и минават през целия онбординг, менюто, покупките и дневника. Интерфейсът е проверен в Chromium на телефонен и компютърен размер, в светъл и тъмен режим; физически iPhone и Android не са проверени.
