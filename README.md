# На масата

Българско приложение за седмично меню, покупки и хранителен дневник. Самостоятелен проект, вдъхновен от потока на mise, с оригинален интерфейс и код.

**Приложение:** https://hristiyantsb.github.io/na-masata/  
**Статус:** v0.6.0 — работеща локална демонстрация и основа за търговска версия. **Не е активен платен SaaS.**

## Започни тук

Ако продължаваш работата с Claude или друг разработчик, прочети **[HANDOFF.md](HANDOFF.md)**. Той описва реализираното, границите и точния ред за довършване.

```sh
npm ci
npm run build:offline
npm test
npm run check
npm run dev
```

Отвори `http://127.0.0.1:4173`. Нужен е Node.js 22.13 или по-нов. За самото приложение няма npm зависимости и няма framework build стъпка. След промени изпълни `npm run build:offline`, за да обновиш офлайн пакета. Всичко в `docs/` е готово за статичен хостинг. GitHub Pages публикува от `main:/docs`.

## Какво работи

- Последователен избор на магазини, домакинство, бюджет, хранене, уреди, изключени продукти, калории и време.
- 23 рецепти, включително варианти за еърфрайър и микровълнова, и растителни протеинови ястия.
- Строги филтри: неподходящите рецепти не се връщат дори при липса на други резултати.
- Подбор на меню, смяна на отделно ястие, връщане, заключване, любими и бележки.
- Агрегирани покупки с наличности вкъщи, редактируема цена и размер на опаковката.
- Хранителен дневник: ръчно въвеждане, порции от рецепта, калории/протеин/въглехидрати/мазнини, редакция, изтриване с връщане, 7-дневен обзор и лична цел.
- Локален баркод декодер ZXing: камера, изображение и ръчно въвеждане. **Няма свързана продуктова база в публичната демонстрация.** Разпознатият код води до честно съобщение и ръчно въвеждане от етикета.
- Резервно копие, валидиран импорт, изтриване, миграция от предишната версия, текстов експорт и schema.org Recipe JSON.
- Отделни модули, тестове, проверки на imports/assets, CI конфигурация, CSP и без inline JavaScript обработчици.

## Ново във v0.5

- Допълнителни продукти извън рецептите: добавяне, редакция, отметки, изтриване с връщане, магазин, количество и незадължителна обща цена.
- Продуктите без въведена цена се показват отделно от известната сума.
- Порции за отделно ястие (1–12), преизчисляване на съставките и покупките, заключване и undo.
- Офлайн пакет за интерфейса, рецептите, шрифтовете и баркод декодера. Изисква успешно първоначално онлайн зареждане; браузърът може да изтрие кеша.
- Обновленията изчакват избор „Обнови“. Кешът не прихваща платежни/акаунт API заявки.
- Икони за началния екран, iPhone инструкции, 60 автоматизирани теста.

## Дневник v0.6

Последни и запазени храни, копиране в няколко дни, изчистване на хранене с връщане, бърз запис, подробни хранителни стойности, CSV export и валидиран JSON импорт от adios. Запазени са последните промени по маскота и onboarding.

[Карта на интеграцията и инструкции за активиране](project/FITNESS-INTEGRATION.md). Email OTP, облачни копия с защита от конфликти и продуктово търсене са реализирани, но **не са конфигурирани или публикувани като реална услуга**. Native Apple login и автоматична синхронизация не са реализирани.

## Какво още НЕ е пуснато

- Платежен доставчик, реални Checkout сесии и клиентски вход.
- Платено заключване на рецепти: настоящият каталог е публичен JavaScript и клиентският код не е защитена платена граница.
- Облачна синхронизация, споделени домакинства и server-side дневник.
- Live цени/наличности на магазини; всички начални цени са примерни.
- Проверена хранителна база; сметките от общи стойности са приблизителни.
- Оценка на ястия по снимка. Endpoint-ът връща `501`, не фиктивни калории.
- Потвърдено визуално и камерно тестване на реален iPhone/Android.

## Произход

Предоставеният запис и статичният анализ чрез [REA](https://github.com/morluto/rea) и Hermes са използвани за разбиране на взаимодействията и схемата „каталог → ограничения → оценка → меню → покупки“. **Не е възстановен или копиран оригиналният код на mise.** REA е инструмент за анализ, не runtime зависимост. Mealie е референция за стандартния Recipe JSON, не основа на изпълнявания клиент.

ZXing е vendored от `@zxing/browser@0.2.1`. Виж [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Снимки или видео на потребителя не се включват в публичното хранилище.
