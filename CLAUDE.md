# На масата — работен контекст за Claude

Първо прочети HANDOFF.md и project/QA.md. Проектът е българско приложение за меню, рецепти, покупки и дневник. Потребителят иска близък до mise поток, класическа плътна кирилица и пряк интерфейс без генерични маркетингови секции.

## Канонична версия

GitHub Hristiyantsb/na-masata; Pages от main:/docs. Frontend v0.5.0, native ES modules; server/ е непубликуван starter. Не сменяй framework без практическа причина.

## Задължително при промяна

1. npm ci
2. Направи необходимата промяна.
3. npm run build:offline
4. npm test
5. npm run check
6. Commit-ни и генерирания docs/sw.js. Не поставяй credentials в docs/.

## Продуктови правила

- Цени: Меню 9 EUR/месец или 90 EUR/година; Плюс 29/290. Плащанията са неактивни.
- Алергени, режим, уреди, време и калориен лимит са твърди ограничения. Не ги премахвай при нула резултати.
- Покупките обединяват съставките, приспадат наличностите и закръглят до опаковки. Ръчните продукти са отделни и остават при ново меню.
- Непозната цена или протеин не означават нула. Цените на магазините са примерни.
- Скенерът разчита баркод; продуктова база и AI анализ не са активирани.
- Данните са локални, не облачни. Офлайн работата изисква първо успешно онлайн зареждане и запазен браузърен кеш.
- Няма избрано ново лого. Пет предложения в brand/concepts/ използват „на маса“. Не внедрявай произволен вариант.

## Приоритет за завършване

Реален мобилен QA → акаунт и безопасна сесия → test-mode backend/Stripe/webhooks → продуктов каталог и правилни единици → отделен AI фотоанализ с потвърждение на порцията. Текущите тестове не доказват production готовност на външните услуги.
